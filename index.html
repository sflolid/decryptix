DECRYPT

How to play
  1. The secret is a 3- to 5-digit code using digits .
  2. Each rule card lists every possible answer to a question, and secretly checks the one the secret gets.
  3. Enter a code and check it against up to 3 cards per round. ✓ means your code gets the same answer as the secret; ✗ means it doesn't.
  4. Use the results to cross off card answers and digits you've ruled out, until only one code fits.
  5. Submit your final answer when you're sure. You only get one, and fewer checks is better.

Tricky cards are harder: they say how far apart two digits are without saying which is bigger, or compare a digit with one of two others but only check one. Harder levels need more checks and more reasoning, not longer codes.

Rule cards

Each card secretly checks one of its answers. Check codes against cards to find out which, and tap answers you've ruled out to cross them off.

Your checks

Every code you've tested, and whether it passed (✓) or failed (✗) each card.
