DECRYPT

How to play

The secret is a code using digits : 3 digits on Easy, 4 on Medium and 5 on Hard. Each card asks a question and lists every possible answer. Every code gets exactly one answer, and the card secretly checks the secret's answer. Tricky cards are harder: some ask how far apart two digits are without saying which is bigger, and some compare a digit with one of two others but only check one of those comparisons.

Enter any code and check it against up to 3 cards per round. A card shows ✓ if your code gets the same answer as the secret, or ✗ if not. Type a new code to start the next round.

Tap an answer on a card to cross it out in your notes; when only one is left it turns green. Under the code, tap a digit to cross it out for that spot (tap again to bring it back); when only one is left in a column it turns green. When you're sure, submit your final answer. You only get one, and your score is how few checks you needed.
